## Descripción
Dashboard estratégico en React que analiza el catálogo de Netflix
(géneros, países y años) para apoyar decisiones sobre producción
de contenido.

## Tecnologías
React, Vite, Recharts, PostgreSQL (Supabase), Vercel.

## Dataset
Netflix Movies and TV Shows (Kaggle).
